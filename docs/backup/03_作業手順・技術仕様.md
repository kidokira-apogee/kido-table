# 作業手順・技術仕様

## 標準フロー
1. Excel受領・最新版確認
2. シート・使用範囲・結合セル・見出し・値型・数式・色等を解析
3. ExcelとWebの項目対応表を作成
4. 掲載用データへ変換
5. 自動検証
6. 既存データ・保持対象を確認
7. 許可範囲でGitHub更新
8. Actions/Pagesデプロイ確認
9. 可能な範囲で本番画面確認
10. 実施・未実施・未確認を分けて報告

## 解析と変換
- ユーザーが指定した最新ファイルを正とする。
- セル位置だけでなく見出し・ブロック構造を使う。
- 馬番を基本キーとする。
- 空欄と0、文字列と数値を区別する。
- 小数点・符号・桁、近走順、コメント原文を保持する。
- 未定義項目を推測しない。
- Excel構造の想定外変更時は処理を止める。

## 公開前チェック
- レース情報・頭数一致
- 全馬の存在、馬番欠落・重複なし
- 馬番と馬名の一致
- 基本情報・近3走・血統・DATA・コメントの対応
- 数値・空欄・色・書式の一致
- 全馬・全項目のWeb表示
- PC・スマートフォン表示
- 既存レース・保持対象の非変更

重大な失敗があれば公開しない。
