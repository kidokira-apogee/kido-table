## 修正内容

1. **ダート見出し配色**
   - 2026-11-05のユーザー承認値を適用。
   - ダート時の `.racehead` 背景を `#70452F`、文字色を白にする。
   - 芝レースは既存正本の緑系配色を維持。
2. **母・母父の囲み**
   - 母名と母父名を同一の `.pedigree-mother` 要素内に配置。
   - TARGET由来の母父側背景色を外側の囲みに適用し、母名の文字色を別途保持。
3. **複勝率強調**
   - 4区分を「1着・2着・3着・着外」として扱う。
   - 分母は4区分の合計、複勝数は上位3区分の合計。
   - 分母3以上、かつ複勝率50%以上で、サマリーチップに `hit`、DATA成績に `good` を付与。
   - 分子・分母の値が数値として確定できない場合は強調しない。
4. **灰色背景**
   - 現行 `index.html` の `normalizeSourceGray(detail)` は構造化JSON・従来HTMLの両方で実行されることを確認。
   - 灰色背景のみを除去し、文字色・他の背景色・値は変更しない。
5. **指数色**
   - 正本CSSのクラスを利用。
   - 80～89：`.metric.index-80`（#00FF00）
   - 90～94：`.metric.index-90`（#F4A09A）
   - 95以上：`.metric.index-95`（#FFC0FF）
   - TARGET背景色で指数色を上書きしない。
6. **タブ内部ID**
   - 正本の `detail` / `distance` / `conditions` / `frame` に合わせた。
   - 表示ラベルは「詳細成績」「距離・コース」「条件別」「枠順・連対実績」。

## 追記：2026-11-07 ソース参照範囲・京都12R識別の再整理

### ソース参照ルール（ユーザー最新指示）
- ①TARGETをレース識別・基本情報の基準とする。
- ②DATE 2・③東スポは、それぞれ指定された必要項目だけを参照する。必要項目以外の記載は、判断材料に含めない。
- ①TARGET内で必要情報の確認に迷った場合は、同じTARGET資料内の別箇所を探してよい。
- ②③の記載を使って、①TARGETのレース日付・条件・基本情報を補正しない。
- 日付だけ、またはR番号だけでレースを決めず、TARGET内の日付・競馬場・R番号・条件・距離・頭数・馬番馬名を組み合わせて識別する。

### 京都12R TARGET原資料で確認した内容
TARGET原資料の冒頭には、次の情報が記載されている。
- 日付：2026年10月31日（土）
- 開催表示：4回京都10日目
- R番号：12R
- 頭数：18頭
- 条件：3歳以上・1勝クラス
- コース：芝1600m・外（B）
- 発走：16:25

したがって、この候補のレース識別に採用する日付は、TARGET基準で **2026-10-31** とする。東スポ原資料の見出し日付（2026-11-01）はコメント抽出の担当範囲外であり、レース識別・日付決定の根拠には使用しない。DATE 2の開催表示等も、指定された抽出項目以外であるため、レース識別の根拠に使用しない。
