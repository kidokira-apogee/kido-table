# 厩舎コメントの記者名・署名除外ルール
更新日：2026年11月20日
適用対象：新・木戸表電子版のExcel解析・コメント変換・公開前検証

## 1. 基本原則
厩舎コメントは原文の意味・内容・語順・表現を維持する。掲載用本文から除外するのは、コメント末尾に付された明確な記者名・記者署名だけとする。要約・言い換え・省略・独自校正は行わない。

このルールは、本番共通フォーマット仕様に既に記載されている「原文は記者名だけ削除し、要約・省略・改変しない」を、変換処理と検証工程に具体化したものである。

## 2. 除去してよいもの
- コメント本文の末尾に、記者名・記者署名として明確に付された文字列。
- コメント本文と署名の境界が原資料上で明確に確認できるもの。

## 3. 除去してはいけないもの
- 本文中に登場する人名・厩舎関係者名・馬名・固有名詞。
- 本文の一部として使われている括弧書き・補足・引用。
- 署名か本文か判別できない文字列。
- 元資料に存在しないと推測した署名や、別コメントから類推した記者名。

曖昧な場合は自動的に削除しない。「要確認」として処理を停止し、原資料を確認する。

## 4. 変換処理
1. コメントブロックを馬番・馬名で特定する。
2. コメント欄の種類（今回コメント、1週間前コメント等）を特定する。
3. 原文を保持し、末尾署名の有無を判定する。
4. 明確な末尾署名だけを除外した掲載用本文を生成する。
5. 署名以外の文字列が変更されていないことを照合する。
6. 署名の判定結果・除去文字列・馬番・馬名・コメント欄を監査ログに残す。原文を公開データに保持しない場合でも、監査可能な変換記録を残す。

単純な正規表現の一括置換だけで、本文中の氏名や括弧書きを削除してはならない。署名パターンは原資料の実例を確認してから実装する。未確認の表記形式を推測で追加しない。

## 5. 公開前必須検査
全馬・全コメント欄について次を確認する。
- [ ] 対象コメントが正しい馬番・馬名に紐付いている。
- [ ] コメント末尾に記者名・署名が残っていない。
- [ ] 除去したのは明確な末尾署名だけである。
- [ ] 本文中の人名・固有名詞・括弧書きが保持されている。
- [ ] 署名以外の本文が原文と一致している。
- [ ] 曖昧な署名候補が「要確認」として残され、推測削除されていない。
- [ ] 今回コメント・1週間前コメント等、掲載対象の全コメント欄を検査した。

**合格条件：** 署名残存0件、意図しない本文改変0件、未解決の曖昧表記0件。
1件でも不合格があれば当該レースを公開しない。一括掲載では対象全レースの検査が終わるまで公開しない。

## 6. 既存公開分の再監査
