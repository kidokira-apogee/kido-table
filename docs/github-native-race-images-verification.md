# GitHubネイティブ画像掲載方式 検証メモ

作成日: 2026-11-15
対象ブランチ: feature/github-native-race-images
基準: main

## 目的
ChatGPT・GitHub・GitHub Pagesのみでレース画像の追加・差し替え・削除を運用できるか検証する。外部画像ストレージ、Cloudflare、外部CMSは使わない。

## 検証方針
- mainは変更しない。専用ブランチで実験する。
- 画像はGit Blob APIのBase64エンコードで登録する。
- 画像パスはレースIDから一意に決める。
- レース画像対応表をJSONで管理する。
- レンダラーは対応表に画像がある場合のみ表示し、ない場合は既存表示を維持する。
- 追加・差し替え・削除はコミット単位で記録する。
- 実画像(PNG/JPEG/WebP)の登録とPagesでの実表示が確認できるまで、運用可能と断定しない。

## 暫定ディレクトリ案
- images/races/{raceId}.{ext}
- data/races/images.json

## 必須検証
1. SVGサンプルでGit Blob APIのBase64登録を確認
2. 画像ファイルのGitHub raw配信を確認
3. PNG/JPEG/WebPの実画像をチャット添付からBase64化し、Blob APIに渡せるか確認
4. Pages上での表示・スマートフォン幅・タップ拡大を確認
5. 差し替え・削除・復旧を確認
6. mainとの差分を確認し、既存レイアウトに影響がないことを確認

## 制約・注意
- リポジトリはPublicのため、登録画像も公開される。
- Gitの履歴に旧画像が残るため、差し替え・削除で過去データが自動的に消えるわけではない。
- GitHub Pagesには容量・帯域等の利用制限がある。
- 本番反映はユーザーの明示承認後に限る。
