# 木戸表電子版 本番共通フォーマット仕様 v1.0
更新日：2026年11月4日（近走騎手名・馬体重増減の表示ルール追加）

## 基準

- 東京9R本番表示を「正本レイアウト」と呼び、唯一無二の視覚・構造上の正解として全レースに適用する。共通実装が正本と異なる場合は実装側を修正する。
- `kido-layout-preview-v2.html` は過去の補助資料であり、正本レイアウト確定後は通常作業で参照しない。DATA項目・カード内容はマスター第15項だけを根拠とする。
承認済み「2026-11-01_東京9R_紅葉ステークス_3段構成・スマホ最適化版.html」を全レース共通の視覚・構造基準とする。既存デザインを維持し、根拠なくフォントや余白を拡大しない。

## 馬カードの順序
1. 基本情報・血統
2. 近3走（独立した「近3走」見出しは表示せず、「前走」「2走前」「3走前」で各走を識別）
3. DATA
4. 厩舎コメント
厩舎コメントはDATA内のサマリー・タブ・各成績表示のすべての後、馬カード内の最後に配置する。

## 基本情報
- 馬名、性齢、斤量、騎手、調教師をプロフィールの全幅エリア内に配置。
- 馬名は独立した1行目、性齢・斤量等の基本情報は必ずその直下の2行目に配置する。馬名の右側へ基本情報を回り込ませない。基本情報行内の折り返しのみ許容し、画面幅や馬名の長さにかかわらず全カードで配置を統一する。
- 馬名はPC20px／スマホ17px、基本ラベル9px、値10pxを目安とする。
- 性齢14px・斤量12px等の独断拡大は禁止。
- 美浦は赤系、栗東は青系。騎手・調教師は本人ごとに所属を確認。未確認を推測で着色しない。
- 血統欄は「母名」「（母父名）」の2行で表示し、母系統名は表示しない。母父名は①TARGETのBM欄など提供元データから取得し、推測で補完しない。配色・スタイルは確認済みHTMLの実装に準拠する。

## 近3走：1走あたり固定3段
前走／2走前／3走前の日付ヘッダーの下に、次の順で3ブロックを縦配置する。
1. レース名（1行目）＋コース・開催条件・騎手・斤量・馬体重・馬場状態（2行目）。2行目は改行せず馬場状態まで表示する。
2. 頭数／馬番／人気／着数／着差／指数／上3F／順／間隔／B の10項目を1列に配置する。
3. 脚質・通過順を同じ段に横並びで配置する。
- 3走は前走→2走前→3走前の順。
- 過去走の騎手名は元データにフルネームがあればフルネームで表示する。姓のみ・2文字への短縮は禁止。元データ自体が略記の場合は、推測で補完せず元データの表記を維持する。
- 馬体重は、元データに増減情報が含まれる場合、体重と増減を併記する（例：506kg（+2）、498kg（-4））。増減情報がない場合は体重のみを表示し、推測や独自計算で補わない。斤量と馬体重を混同しない。
- 元データにフルネームまたは馬体重増減が存在する場合、生成HTMLにもその情報が残っていることを全馬・全3走で照合する。
- スマートフォンで横スクロール・2段折返し・省略・切り落としを発生させない。
- タイトル約9px、項目ラベル8.5〜9px、値9.5〜10pxを目安にする。
- コース・条件行をnowrapにするが、overflow:hiddenで「良」等の末尾を隠さない。

## 脚質の表示変換
- 近3走の脚質欄は、保存値を変更せず、共通表示プログラムで画面表示時だけ、元データが略号の場合に次の正式表記へ変換する。
  - 逃 → 逃げ
  - 先 → 先行
  - 中 → 中団
  - 後 → 後方
  - マ → マクリ
- 変換対象は近3走の各「脚質」値のみとする。DATAタブ内の集計ラベル・統計項目名など、別用途の文字列には適用しない。
- 「—」「－」など上記にない値は変更しない。すでに正式表記になっている値もそのまま表示する。
- 元データやJSON内の保存値は改変せず、画面表示時に変換する。

## DATA

### 1. 上部サマリー
上部サマリーは次の5項目で構成する。

1. 全成績：全競走の成績を表示する。
2. 芝成績／ダート成績：今回のレースの芝・ダート区分に対応する成績を表示する。
3. 今回コース条件：今回の開催場における成績を表示する。距離を組み合わせた成績ではなく、開催場単位の成績を使用する。
   - 例：今回の開催場が東京なら「東京」の成績を表示する。
   - 例：今回の開催場が京都なら「京都」の成績を表示する。
   - 「東京芝1600m」など、開催場に距離・芝ダート条件を組み合わせた成績は上部サマリーには表示しない。これらの距離・コース別成績は、後続の「距離・コース」内で扱う。
   - 開催場単位の成績は、元データの開催場行（例：「東京」「京都」）から取得する。芝・ダートや距離を付加した別条件の成績で代用しない。
   - 元データに開催場単位の成績がない場合は、別条件の数値を流用せず「—」を表示し、データ不足として扱う。
4. 回り成績：今回のコース条件に対応する右回り・左回りの成績を表示する。
5. 出遅れ率：出遅れ率を表示する。

### 共通表示・着色ルール
- 既存の数値・カード・タブ・切替機能を維持する。
- 成績着色条件：分母3以上かつ複勝率50%以上。分母は1〜3着＋その他の合計、複勝率は1〜3着を分子とする。
- 出遅れ率25%以上は青系背景。
- 上部サマリー以外のDATA抽出項目・タブ構成は、別途定めるDATAマスターに従う。

## 厩舎コメント
- DATAのすべての表示要素の後、馬カード内の最後に枠付きコメントカードで掲載。
- 薄い緑系の枠線・白背景・角丸を維持。
- 厩舎名を見出しにする。原文は記者名だけ削除し、要約・省略・改変しない。
- イチ押し指定は黄色系背景。G1の1週前・前走コメント等の追加情報も保持。
- 「東スポコメント」など出典見出しは表示しない。

## 実装・検証

- 正本レイアウト以外の補助HTMLを視覚デザインや配置の根拠にしない。データ処理工程は原本受領→抽出→照合→確定JSON変換→検証→正本レイアウト反映→本番確認とする。
- 共通レイアウトはindex.htmlの共通CSSで管理し、JSONごとの独自フォント・段組CSSを追加しない。
- 全馬について馬番・馬名、近3走3件、10項目、コメント位置、DATAタブ対応を検証。
- スマホ320／360／390pxとPC幅で横はみ出し・文字切れを検証する。

## 2026年11月10日追加変更：Excelセルの文字色・背景色の反映ルール

- ①の情報に含まれるセルの文字色とセル背景色を、原則としてWeb表示へそのまま反映する。
- ただし、Excelでベース背景色として使用されている色（現行入力ファイルの `#E8E8C8`）は無色扱いとし、Webへ背景色を反映しない。
- 灰色に着色されたセルも無色扱いとし、Webへ背景色を反映しない。
- 文字色は上記の背景色例外とは独立して扱い、元セルの文字色を保持する。
- 指数欄は専用の指数着色ルールを最優先とする。指数セルに設定された一般のセル背景色で指数専用の背景色を上書きしない。
- 上記は装飾上の推測ではなく、Excelの書式情報を反映する際の本番共通ルールとする。
