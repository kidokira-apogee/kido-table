# 木戸表電子版 本番共通フォーマット仕様 v1.0
更新日：2026年11月4日（近走騎手名・馬体重増減の表示ルール追加）

## 基準
承認済み「2026-11-01_東京9R_紅葉ステークス_3段構成・スマホ最適化版.html」を全レース共通の視覚・構造基準とする。既存デザインを維持し、根拠なくフォントや余白を拡大しない。

## 馬カードの順序
1. 基本情報・血統
2. 近3走（独立した「近3走」見出しは表示せず、「前走」「2走前」「3走前」で各走を識別）
3. DATA
4. 厩舎コメント
厩舎コメントはDATA内のサマリー・タブ・各成績表示のすべての後、馬カード内の最後に配置する。

## 基本情報
- 馬名、性齢、斤量、騎手、調教師をプロフィールの全幅エリア内に配置。
- 馬名は独立した1行目、性齢・斤量等の基本情報は必ずその直下の2行目に配置する。馬名の右側へ基本情報を回り込ませない。基本情報行内の折り返しのみ許容し、画面幅や馬名の長さにかかわらず全カードで配置を統一する。
- 馬名はPC20px／スマホ17px、基本ラベル9px、値10pxを目安とする。
- 性齢14px・斤量12px等の独断拡大は禁止。
- 美浦は赤系、栗東は青系。騎手・調教師は本人ごとに所属を確認。未確認を推測で着色しない。
- 血統名・母系統・配色を維持する。

## 近3走：1走あたり固定3段
前走／2走前／3走前の日付ヘッダーの下に、次の順で3ブロックを縦配置する。
1. レース名（1行目）＋コース・開催条件・騎手・斤量・馬体重・馬場状態（2行目）。2行目は改行せず馬場状態まで表示する。
2. 頭数／馬番／人気／着数／着差／指数／上3F／順／間隔／B の10項目を1列に配置する。
3. 脚質・通過順を同じ段に横並びで配置する。
- 3走は前走→2走前→3走前の順。
- 過去走の騎手名は元データにフルネームがあればフルネームで表示する。姓のみ・2文字への短縮は禁止。元データ自体が略記の場合は、推測で補完せず元データの表記を維持する。
- 馬体重は、元データに増減情報が含まれる場合、体重と増減を併記する（例：506kg（+2）、498kg（-4））。増減情報がない場合は体重のみを表示し、推測や独自計算で補わない。斤量と馬体重を混同しない。
- 元データにフルネームまたは馬体重増減が存在する場合、生成HTMLにもその情報が残っていることを全馬・全3走で照合する。
- スマートフォンで横スクロール・2段折返し・省略・切り落としを発生させない。
- タイトル約9px、項目ラベル8.5〜9px、値9.5〜10pxを目安にする。
- コース・条件行をnowrapにするが、overflow:hiddenで「良」等の末尾を隠さない。

## 厩舎コメント
- DATAのすべての表示要素の後、馬カード内の最後に枠付きコメントカードで掲載。
- 薄い緑系の枠線・白背景・角丸を維持。
- 厩舎名を見出しにする。原文は記者名だけ削除し、要約・省略・改変しない。
- イチ押し指定は黄色系背景。G1の1週前・前走コメント等の追加情報も保持。
- 「東スポコメント」など出典見出しは表示しない。

## DATA
- 既存の数値・カード・タブ・切替機能を維持。
- 成績着色条件：分母3以上かつ複勝率50%以上。分母は1〜3着＋その他の合計、複勝率は1〜3着を分子とする。
- 出遅れ率25%以上は青系背景。DATA抽出項目・タブは現行マスターに従う。

## 実装・検証
- 共通レイアウトはindex.htmlの共通CSSで管理し、JSONごとの独自フォント・段組CSSを追加しない。
- 全馬について馬番・馬名、近3走3件、10項目、コメント位置、DATAタブ対応を検証。
- スマホ320／360／390pxとPC幅で横はみ出し・文字切れを検証する。
